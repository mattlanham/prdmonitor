## Codebase Patterns

### Project Structure
- Entry point: `main.go` with minimal logic, delegates to internal packages
- Data models in `internal/model/model.go`
- Tests use Go's `testing` package with `t.TempDir()` for temp directories
- Config struct pattern for CLI configuration

### CLI Argument Parsing
- `ParseArgs(args []string)` takes os.Args to allow testing
- Returns `*Config, error` pattern for validation
- Errors are printed to stderr, exit code 1 for failures

### Error Handling
- Use `fmt.Errorf` with `%w` for wrapping errors
- Check `os.IsNotExist(err)` for cleaner error messages
- Validate directory is readable by attempting to open it

### Scanner Package
- Use `filepath.WalkDir` for recursive directory traversal (more efficient than `filepath.Walk`)
- Return `*ScanResult` with both files and non-fatal errors
- Convert paths to absolute using `filepath.Abs()` for consistency
- Custom error types (e.g., `NotADirectoryError`) for specific error handling
- Module name is `lanham/prdmonitor` (important for internal imports)
